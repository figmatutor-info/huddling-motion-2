## 3. 새 후보

motion.md 3장 "새 후보" 형식. 승인 전엔 쓰지 않음. 숫자는 레퍼런스 측정값이며 우리 값이 아니다 (쓰게 되면 배율 · 길이는 docs 이름으로 정해야 함).
work/launch-30s/decisions.md · motion.md 3장 후보 목록과 대조함 — 아래 두 개는 어느 쪽에도 없음.

| 후보 | 무엇 | 왜 후보인가 |
|---|---|---|
| `punch-cut` | 같은 logo를 와이드(앞쪽만 보이게 크게) → 클로즈(더 크게, 끝 쪽)로 하드컷. 직전 움직임 방향이 컷 너머로 이어짐 (측정: 1.71배, 클로즈 첫 프레임 오른쪽 8px · 아래 24px에서 출발) | `transition`은 다음 장면으로의 컷, `match-cut`은 "같은 자리 · 같은 크기"라 크기 점프가 없음. 로고를 화면보다 크게 자르는 배치도 video.md에 없음 (`logo-hero`만) |
| `settle-overshoot` | 들어와 멈출 때 목표를 살짝 넘었다 되돌아와 안착 (측정: 8f, 넘는 양 5px@720 ≈ 영상 3–4px@540) | 1장 Easing "목표값을 넘었다 돌아오는 곡선은 없다"와 반대 · 해당 easing 토큰 없음 |

기존 후보와 겹친 것 (새로 쓰지 않음)

- 기존 후보와 같음: `cam-push` (motion.md 5장 아래) — 7 Push, 마지막 프레임까지 가속 확대 (측정: 18f, × 1 → 1.30). 다름: `ease-in`처럼 가속 · 멈추지 않고 영상이 끝남 (4장 `hold-end`와 충돌)
- 기존 후보와 같음: `cam-drift` · `cam-pan` (motion.md 5장 아래) — 3 Drift, 컷 직전 가속하며 옆으로 미끄러짐 (측정: 11f, ≈ 30px@960)
