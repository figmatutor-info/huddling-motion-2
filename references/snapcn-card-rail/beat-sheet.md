# beat-sheet — snapcn-card-rail

- 근거: `source.md`(글 문서 페이지 요약)와 `poster.webp`(640×360 한 장)만. 데모 영상 · 프레임 없음 → 프레임 추출 안 함.
- 영상 launch-d에서의 역할: 전환만 (카드 줄을 튕겨 다음 카드로 넘기는 방식). 뼈대 · 글자 배치는 skillry-lnkiai, 카메라는 remotion-device-rise, 구도는 snapcn-phone-frame 비트 시트를 따른다.
- 원본 길이: 표기 3.6초 = 108f. 예시 코드 54f는 튕김 3번 · 30f 간격(최소 90f)이 들어가지 않아 비율 기준으로 쓰지 않는다. 첫 튕김 시작 프레임은 source에 없어 0f로 둔 추정 비율이다.
- 가져오지 않는 것: 카드 디자인 · 사진 · 그라디언트 바탕색 · 제목 문구 · 태그 문구 (CLAUDE.md 4번). "측정" = source · poster에서 잰 값이며 쓰지 않는다. 쓸 값은 docs 이름.

### 다른 후보를 고르지 않은 이유
- 5장 `cam-pan`: 같은 가로 이동이지만 카메라가 움직이면 고정 제목도 같이 밀린다. 원본은 제목이 서 있고 카드 줄만 움직이므로 카드 줄 이동(`skill-carousel`) + `cam-hold`.
- 3장 `skill-list` · `asset-list`: 위에서 차례로 쌓이는 등장이라 "옆으로 넘김" 전환이 아님.
- 3장 `screen-change` (컷): 원본은 카드 사이가 컷이 아니라 미끄러짐으로 이어진다.

## 2. 새 후보 (motion.md 3장 "새 후보" 형식 · 승인 전엔 쓰지 않음)

| 후보 | 무엇 | 왜 후보인가 |
|---|---|---|
| `rail-tilt` | 카드 줄이 놓인 평면을 가로축으로만 뒤로 눕힘 (rotateX만, rotateY 0) · perspective는 `crane-angle`과 같은 2400px · 글자(영상 제목)는 눕히지 않음. 측정: 평면 아래 폭이 위 폭의 약 1.2배 | 1장에 rotateX만의 각도 토큰이 없음 (`crane-angle`은 rotateY -18°가 같이 있음). 각도 숫자를 사람이 정해야 함 (snapcn card-rail 비트 1–3) |
| `card-rail` | 서로 다른 카드 부품을 가로 한 줄로 놓고 `skill-carousel`처럼 한 장씩 튕겨 넘김 (예: skill-card-1 → mission-card → badge-approved → stat-card → asset-card, BRIEF 흐름 순서) · 튕김 `dur-2xl` · `ease-out` · 사이 hold 없음 | 3장 `skill-carousel` 대상은 skill-card 1 · 2 · 3뿐. 섞으면 (1) 바탕 충돌 — video.md 5장: skill · stat은 `video-bg-soft`, asset-card는 `video-bg`만 (2) 높이가 다른 부품(246 · 708 · 283 · 207)의 세로 정렬 기준이 docs에 없음 (3) badge-approved는 카드 폭이 아님 → 피치 기준이 없음 (snapcn card-rail 비트 1–3 · "6장 이상") |

튕김 자체(거리 · 길이 · 곡선)는 새 후보가 아니다. `skill-carousel` + `ease-out` · `dur-2xl` · `hold-m` 없음으로 docs 토큰만으로 조립되므로 decisions.md에 `장면 · skill-carousel(튕김) · ease-out + dur-2xl + video-gap · snapcn-card-rail 비트 1–3`으로 남기고 쓴다.

## 이 레퍼런스의 시각 규칙

1. 그리드: 카드가 같은 피치(카드 폭 + `video-gap`)로 가로 한 줄, 가운데 한 장이 화면 가로 가운데에 서고 양옆 카드는 화면 가장자리에서 잘린다.
2. 구도: 화면 전체 · `cam-hold`. 위 = 고정 제목, 아래 = 카드 줄 (원본은 기운 평면 → `rail-tilt` 승인 전엔 평면 없이). 줄의 시작은 첫 카드 앞이 비어 있다.
3. 글자 배치: 영상 글자는 위 가운데 한 줄(13자 내외)만, 튕김 동안 움직이지 않고 바로 선다. 그 밖의 글자는 카드 부품 안에만 (0장 "부품 장면에는 부품만" 대신 — `대신:` 기록).
4. 전환: 카드 사이 전환은 컷이 아니라 튕김 — 카드 한 칸씩 왼쪽으로 `dur-2xl` · `ease-out` (빠른 출발 · 긴 감속, 넘침 없음). 장면 경계는 뼈대를 따름.
5. 리듬: 튕김을 `dur-2xl` 간격으로 멈춤 없이 이어 3번 (우리 skill-card로는 2번), 감속 꼬리가 머묾 역할을 하고 마지막 튕김 뒤에만 `hold-m`.
